API ni Sinab Ko'rish Metodlar Darsligi

HTTP So'rov Turlari (Methods) Qanday Ishlaydi?

REST API da har bir operatsiya uchun maxsus HTTP metodi ishlatiladi:

GET

Ma'lumot olish

Faqat ma'lumotni o'qish uchun ishlatiladi. Serverdagi ma'lumotni o'zgartirmaydi (Idempotent).

GET /api/books
GET /api/books/1
POST

Yangi ma'lumot qo'shish

Yangi kitob yaratadi. Ma'lumotlar body (JSON) orqali yuboriladi.

POST /api/books
Status: 201 Created
PUT

To'liq yangilash

Obyektni boshidan to'liq almashtiradi. Barcha maydonlar yuborilishi shart!

PUT /api/books/1
Body: barcha maydonlar
PATCH

Qisman yangilash

Faqat o'zgartirmoqchi bo'lgan 1-2 ta maydonni yuborasiz (masalan, faqat name).

PATCH /api/books/1
Body: { name: "Yangi nom" }
DELETE

Ma'lumotni o'chirish

ID bo'yicha ko'rsatilgan kitobni JSON fayldan butunlay o'chirib tashlaydi.

DELETE /api/books/1
Status: 200 OK
CORS

CORS sozlamasi

Frontend (masalan React) boshqa port yoki domenda tursa ham bemalol so'rov yuborishi mumkin.

origin: * (Hammasiga ochiq)
